# Luiz Lara — Academic homepage

Academic homepage with a sidebar profile, a light background, and muted burgundy links. Built with plain HTML, CSS and JavaScript; no Jekyll, installation or build step is required.

## Edit

- `index.html`: biography, research, publications, teaching, contact.
- `styles.css`: layout and colors, defined as CSS variables at the top.
- `script.js`: highlights the current section in the navigation.

Open `index.html` directly or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## GitHub Pages

Publish the repository root. `.nojekyll` disables Jekyll processing. PDFs, existing image assets and the license are retained; the former Jekyll theme files are removed. Earlier versions remain in Git history.

## Validation

Layout and navigation checked in a desktop browser and at 390px mobile width. No horizontal overflow or missing internal anchor destinations, and no JavaScript errors. External destinations have not all been rechecked.
